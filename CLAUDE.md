# Cribbage — notes for Claude

Two-player cribbage to 121 in the browser, built for Tim to play on his iPhone and
laptop. You play the computer (easy / medium / hard) or the Daily game. Online play is
off and hidden (stopped by the Online guard, see PROGRESS.md). No accounts, no build
step, no dependencies for the site itself.

- Live: https://timothyhadfield.github.io/cribbage/ (GitHub Pages from `main`, root folder)
- Repo: `TimothyHadfield/cribbage` (public). Footer link `../` goes to the Board & Card Games hub.
- Read `PROGRESS.md` first (state, decisions, traps).

## File map
- `index.html` — all markup and game CSS; plain `<script>` tags with `?v=` cache tags (bump on change).
- `js/score.js` — scoring. `scoreHand` (itemised) and `handValue` (fast) are two implementations on purpose; tests cross-check them. Cards are integers 0-51.
- `js/engine.js` — pure state machine: deal, discard, cut, pegging, show (with optional muggins `claim`), 121 stop, skunks. `award()` is the only place points are added.
- `js/ai.js` + `js/crib-ev.js` — computer; `crib-ev.js` is generated by `tools/build-crib-ev.js`.
- `js/local.js` — vs-computer transport: seeded deals, undo, `snapshot()`/`resume()`.
- `js/board.js` — SVG wooden peg board with leapfrog hops.
- `js/ui.js` — DOM builders (cards via the table kit). `js/app.js` — controller (screens, sheets, sounds, save/resume, stats).
- `js/profile-crib.js` — My stats glue: levels (measured Elo), achievements, result mapping.
- Shared kit copies, byte-identical, never edit here: `js/table.js`, `css/table.css` (`_table` 1.0.2), `js/fx.js` (`_fx` 1.0.3), `js/profile.js`, `css/profile.css` (`_profile` 1.0.1).
- Dead, not loaded: `js/online.js`, `js/firebase-config.js`, `firestore.rules`, `firebase.json`, `test/rules.test.js` (old own-project online setup).
- `tools/measure-levels.js` — self-play Elo gaps between levels.

## Run locally
`python -m http.server <random high port> --bind 127.0.0.1` in the repo root (background option), then open it. `App.current` and `Local` in the console drive scripted checks.

## Test
- `node test/score.test.js`, `engine.test.js`, `ai.test.js`, `muggins.test.js`, `local.test.js` — seconds each.
- `node test/exhaustive.test.js` — about 6 minutes; run after any change to `score.js` or `engine.js`.
- `node tools/measure-levels.js 3000` — a few minutes; re-run after AI changes and update `js/profile-crib.js` LEVELS.

## Deploy
Push to `main`; GitHub Pages rebuilds. `python ~/.claude/hooks/live-check.py <repo path>` waits for it.

## Decisions (don't relitigate)
- Online only through the shared `_online` + Firestore `th-board-games`, and only if it passes the Online guard (it didn't, 2026-10-27).
- Muggins off by default. Games vs computer rated unless Hint/Undo used.
- `handValue` duplicating `scoreHand` is intentional. Log lines use "Name: thing" because one player is "You". "Go" is automatic.

## Traps
- Peg board gradient ids must be unique per board (Chrome picks the first `#id`, and the menu board is hidden).
- `publicView.log` is the last 12 lines; use `logCount` for "what's new".
- No test account exists. Keep anything under `.claude/test/` out of git.
